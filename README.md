# 月末得点予測

index.htmlをブラウザで開いて利用します。ビルド・通信は不要です。

土日・日本の祝日は自動で休みとして計算し、16日〜月末の休日出勤日を日付で追加します。個人休暇日数は勤務予定日から別途差し引きます。重複した日付や通常の平日を追加しても二重加算しません。

祝日データはholiday-jp/holiday_jp（MIT）から2026年10月19日に取得した2025〜2027年分を内蔵しています。利用時の自動更新はありません。対象年以外は計算を止めます。祝日データの改定時は更新してください。

元Excelの6名の集計値と2026年10月15日得点を使用しています。

## GitHub Pagesでの公開

GitHubリポジトリの Settings → Pages → Build and deployment で、Source を Deploy from a branch、Branch を main、フォルダを / (root) にして Save します。

公開先（Pages有効化後）: https://gpamjl.github.io/C-/

index.htmlには個人名と実績が含まれます。公開サイトから閲覧できるデータです。

個人休暇は日数のプルダウン、休日出勤はカレンダーで選びます。土日祝算定は別途1回2,500点を加算します。

## パスワード版への更新

index.htmlは共通パスワードで復号する暗号化版です。パスワードはリポジトリに保存しません。HTTPSまたはローカルファイルとして開いて使用します。再読み込みするとログイン画面へ戻ります。暗号化前のアプリを要求するsetup.htmlは削除しました。

注意：過去コミットには暗号化前の個人データが残ります。現在のHTMLの暗号化は過去コミットを保護しません。GitHub Pagesの公開範囲とは別に、リポジトリの公開範囲・履歴の管理が必要です。

## 個人別月末実績

ログイン後、history.jsが個人別の月末実績入力と折れ線グラフを追加します。元データの後半増加得点を月末実績として流用しません。月末実績は各利用者が月ごとに入力します。同じ個人・月は確認後に更新できます。

実績はWeb Crypto AES-GCMで暗号化し、ブラウザのlocalStorageに保存します。再ログイン時に同じ共通パスワード由来の鍵で復号します。端末・ブラウザ・オリジンが変わると保存領域は異なり、自動同期しません。プライベートモードやブラウザデータ削除では消失する場合があります。暗号化JSONバックアップと復元を利用できます。同じパスワード・同じアプリの鍵設定が必要です。共有端末で共通パスワードを使う利用者間のデータ分離はありません。

index.htmlとhistory.jsを同じ公開ディレクトリに配置してください。パスワードは変更していません。1440 / 768 / 390 / 320px幅で画面の横はみ出し、個人切り替え、登録・更新・削除、再ログイン保存復元、暗号化バックアップと読み込みをブラウザで検証しています。
