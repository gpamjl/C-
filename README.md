# 月末得点予測

index.htmlをブラウザで開いて利用します。ビルド・通信は不要です。

土日・日本の祝日は自動で休みとして計算し、16日〜月末の休日出勤日を日付で追加します。個人休暇日数は勤務予定日から別途差し引きます。重複した日付や通常の平日を追加しても二重加算しません。

祝日データはholiday-jp/holiday_jp（MIT）から2026年10月19日に取得した2025〜2027年分を内蔵しています。利用時の自動更新はありません。対象年以外は計算を止めます。祝日データの改定時は更新してください。

元Excelの6名の集計値と2026年10月15日得点を使用しています。

## GitHub Pagesでの公開

GitHubリポジトリの Settings → Pages → Build and deployment で、Source を Deploy from a branch、Branch を main、フォルダを / (root) にして Save します。

公開先（Pages有効化後）: https://gpamjl.github.io/C-/

index.htmlには個人名と実績が含まれます。公開サイトから閲覧できるデータです。

個人休暇は日数のプルダウン、休日出勤はカレンダーで選びます。土日祝算定は別途1回2,500点を加算します。
